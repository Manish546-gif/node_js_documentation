🚀 GETTING STARTED

1. Navigate to the web directory:
   $ cd /workspaces/node_js_documentation/web

2. Install dependencies:
   $ npm install

3. Start the development server:
   $ npm run dev

4. Open in your browser:
   → http://localhost:5174

5. Start exploring Node.js documentation!
